خطوات الشغل (٤ مربعات)

التواصل

مثال العراق: 964 ثم الرقم بدون الصفر. هذا الرقم يشتغل بكل أزرار الواتساب بالموقع.

السوشيال ميديا

اتركه فارغ إذا ما عندك حساب — الأيقونة تختفي من الموقع تلقائياً.

الخدمات — الترقيم يتحدث تلقائياً

المشاريع

القسم: ريلز / فوتو / TVC — هو اللي يحدد تحت أي فلتر يظهر المشروع.
الميديا: حط رابط صورة أو فيديو. ارفع الملف بمجلد assets واكتب مثلاً assets/work-1.jpg أو حط رابط كامل.

فريق العمل

إذا ما حطيت صورة، راح تظهر أيقونة من أيقونات الهوية.

أرقام النتائج

الرقم يتحرك ويعد لحد الرقم المكتوب. اللاحقة مثل + اختيارية.

أسماء العملاء

تظهر بالشريط المتحرك. كل سطر اسم عميل.

اكتب كل اسم بسطر لحاله.

النشر المباشر على الموقع

حتى تنشر تعديلاتك على الموقع مباشرة بدون ما تحتاج أحد، تحتاج مفتاح وصول من GitHub. تسويه مرة وحدة بس.

خطوات إنشاء المفتاح:
١. افتح هذا الرابط
٢. Repository access ← Only select repositories ← اختر action-agency-website
٣. Permissions ← Repository permissions ← Contents ← اختر Read and write
٤. Generate token، وانسخ المفتاح والصقه تحت
مهم عن الأمان: المفتاح ينحفظ بمتصفحك أنت بس، ما ينرفع للموقع ولا يشوفه أحد غيرك. بس لا تفتح لوحة التحكم من جهاز مشترك أو عام. إذا شكيت بشي، امسح المفتاح من هنا وألغيه من إعدادات GitHub.

نسخ احتياطية

«تنزيل نسخة» ينزّل ملف content.json — احتفظ بيه كنسخة احتياطية. إذا صار شي غلط ترفعه مرة ثانية.

ما عندي مفتاح — شلون أنشر؟

اضغط «تنزيل الملف» فوق، وراح ينزل ملف اسمه content.json. ارفعه بمستودع GitHub مكان الملف القديم (اسحبه وأفلته بصفحة المستودع)، والموقع يتحدث خلال دقيقة تقريباً.
