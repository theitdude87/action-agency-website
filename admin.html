فيديو التعريف (الشوريل)

اسم الوكالة والشعار يظهرون فوق الفيديو تلقائياً.

تظهر بالأبيض والأسود، وتصير ملوّنة لمن يشتغل الفيديو. اضغط «رفع صورة» واختر من جهازك — تتصغّر وتترفع لوحدها.

يقبل يوتيوب، فيميو، أو ملف فيديو ترفعه بمجلد assets. إذا تركته فارغ، يظهر الغلاف وزر التشغيل بس بدون ما يشتغل شي.

يشتغل مكتوم لأن المتصفحات ما تسمح بصوت بدون ضغطة، ويظهر زر «تشغيل الصوت» فوق الفيديو. يشتغل بس إذا الفيديو ملف مرفوع عندك (مو رابط يوتيوب).

التواصل

مثال العراق: 964 ثم الرقم بدون الصفر. هذا الرقم يشتغل بكل أزرار الواتساب بالموقع.

هذا اللي تطلع عليه الخريطة بالموقع. تكدر تحط اسم المكان أو كود الموقع (Plus Code).

افتح موقعك بخرائط جوجل ← مشاركة ← انسخ الرابط والصقه هنا.

السوشيال ميديا

اتركه فارغ إذا ما عندك حساب — الأيقونة تختفي من الموقع تلقائياً.

نسخ احتياطية

«تنزيل نسخة» ينزّل ملف content.json — احتفظ بيه كنسخة احتياطية. إذا صار شي غلط ترفعه مرة ثانية.

الخدمات — الترقيم يتحدث تلقائياً

المشاريع

القسم: ريلز / فوتو / TVC — هو اللي يحدد تحت أي فلتر يظهر المشروع.
الميديا: حط رابط صورة أو فيديو. ارفع الملف بمجلد assets واكتب مثلاً assets/work-1.jpg أو حط رابط كامل.

فريق العمل

إذا ما حطيت صورة، راح تظهر أيقونة من أيقونات الهوية.

أرقام النتائج

الرقم يتحرك ويعد لحد الرقم المكتوب. اللاحقة مثل + اختيارية.

أسماء العملاء

تظهر بالشريط المتحرك. ارفع لوكو العميل بمجلد assets/clients واكتب مساره. كل اللوكوات تتحول أبيض تلقائياً بنفس الارتفاع حتى الشريط يبقى مرتب. إذا تركت اللوكو فارغ، يظهر اسم العميل بدله.

النشر المباشر على الموقع

حتى تنشر تعديلاتك على الموقع مباشرة بدون ما تحتاج أحد، تحتاج مفتاح وصول من GitHub. تسويه مرة وحدة بس.

خطوات إنشاء المفتاح:
١. افتح هذا الرابط
٢. Repository access ← Only select repositories ← اختر action-agency-website
٣. Permissions ← Repository permissions ← Contents ← اختر Read and write
٤. Generate token، وانسخ المفتاح والصقه تحت
مهم عن الأمان: المفتاح ينحفظ بمتصفحك أنت بس، ما ينرفع للموقع ولا يشوفه أحد غيرك. بس لا تفتح لوحة التحكم من جهاز مشترك أو عام. إذا شكيت بشي، امسح المفتاح من هنا وألغيه من إعدادات GitHub.
ما عندي مفتاح — شلون أنشر؟

اضغط «تنزيل الملف» فوق، وراح ينزل ملف اسمه content.json. ارفعه بمستودع GitHub مكان الملف القديم (اسحبه وأفلته بصفحة المستودع)، والموقع يتحدث خلال دقيقة تقريباً.

تفعيل النشر

حتى تنشر تعديلاتك على الموقع مباشرة، اللوحة تحتاج مفتاح وصول من GitHub. تسويه مرة وحدة بس وينحفظ بهذا المتصفح.

خطوات إنشاء المفتاح:
  1. افتح صفحة إنشاء المفتاح
  2. Token name: اكتب أي اسم، مثلاً action-site
  3. Repository access ← Only select repositories ← اختر action-agency-website
  4. Permissions ← Repository permissions ← Contents ← Read and write
  5. اضغط Generate token وانسخ المفتاح والصقه تحت

المفتاح ينحفظ بهذا المتصفح بس، وما ينرفع للموقع ولا يشوفه أحد غيرك.
