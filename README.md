# ACTION AGENCY — Website

موقع **اكشن ايجنسي** — وكالة إنتاج وإعلان.
**WE BRING HEAT TO BRANDS**

صفحة واحدة (Single page)، عربي + انكليزي، متجاوبة مع الموبايل، مبنية على هوية الشركة الرسمية.

---

## 🎨 الهوية البصرية / Brand

الألوان مأخوذة مباشرة من ملفات الهوية الرسمية (أحادية اللون بالكامل):

| اللون | Hex | الاستخدام |
|---|---|---|
| الغامق | `#212121` | الخلفية الأساسية |
| الفاتح | `#cfcfcf` | اللوكو، النصوص، الأزرار |

**الخطوط:** Montserrat (انكليزي + الأرقام) · Tajawal (عربي)
**قفل اللوكو:** `ACTION` عريض + `AGENCY` رفيع مفتوح التباعد

---

## ✅ الميزات

- **مقدمة الكلاكيت** — اللوكو ينطبق ويعد ٣ ← ٢ ← ١ ← ACTION ثم يفتح الموقع
- **عربي / انكليزي** — زر تبديل بالهيدر، يقلب اتجاه الصفحة RTL/LTR ويتذكر اختيارك
- **قسم المشاريع** — فلاتر: الكل · ريلز · فوتو · TVC
- **واتساب** — زر عائم + أزرار بالهيدر والهيرو والفوتر
- **اللوكو متحرك بالخلفية** — نمط الكلاكيت المكرر من فريم الهوية
- **شريط الفيلم** المتحرك بين الأقسام
- **١١ خدمة** بترقيم مطابق لسلايد الخدمات الرسمي
- متجاوب بالكامل + يحترم `prefers-reduced-motion`

## 🎛️ لوحة التحكم — `admin.html`

**كل محتوى الموقع يتعدّل من اللوحة بدون ما تفتح الكود أبداً.**

افتح: **`<رابط الموقع>/admin.html`**

### شنو تكدر تعدّل
| التبويب | المحتوى |
|---|---|
| عام | الشعار، نصوص الواجهة، من نحن، خطوات الشغل، الواتساب، الإيميل، العنوان، السوشيال |
| الخدمات | إضافة / حذف / ترتيب الخدمات (الترقيم يتحدث لوحده) |
| المشاريع | إضافة مشاريع، القسم (ريلز/فوتو/TVC)، الصور والفيديوهات |
| الفريق | أعضاء الفريق، المناصب، الصور |
| النتائج | الأرقام والأوصاف |
| العملاء | أسماء العملاء بالشريط المتحرك |

### كيف تنشر تعديلاتك
**الطريقة الأولى — نشر مباشر (الأسهل):**
سوِّ مفتاح وصول من GitHub مرة وحدة (الخطوات مشروحة داخل اللوحة بتبويب «الربط والنشر»)،
وبعدها كل ما تعدّل شي اضغط **نشر على الموقع** والموقع يتحدث خلال دقيقة.

**الطريقة الثانية — بدون مفتاح:**
اضغط **تنزيل الملف** ← ينزل `content.json` ← ارفعه بمستودع GitHub مكان الملف القديم.

> تعديلاتك تنحفظ بالمتصفح أول بأول، فلو سكّرت الصفحة بالغلط ما تروح.
> لازم تضغط «نشر» حتى تظهر للناس.

## ⚙️ المطلوب تعبئته / TODO before launch

### ١. رقم الواتساب (مهم)
من لوحة التحكم ← تبويب **عام** ← حقل رقم الواتساب.
الصيغة دولية **بدون `+` وبدون صفر البداية**. مثال العراق: `9647701234567`.

### ٢. الميديا الحقيقية
ارفع الصور والفيديوهات بمجلد `assets`، وبعدها من اللوحة ← **المشاريع** ← حقل الميديا
اكتب مثلاً `assets/work-1.jpg` أو `assets/work-1.mp4`.

### ٣. لوكوات العملاء
حالياً أحرف أولى مولّدة. الأسماء تتبدل من اللوحة، وإذا تريد لوكوات حقيقية
بدّلها بصور مع الإبقاء على `class="client-logo"` حتى يبقى القياس موحد.

### ٤. بيانات التواصل
الإيميل والعنوان — من اللوحة ← تبويب **عام**.

## 🚀 التشغيل

افتح `index.html` بالمتصفح مباشرة — ما يحتاج سيرفر ولا build.

> **ملاحظة للنشر النهائي:** الموقع يحمّل Tailwind من CDN، وهذا ممتاز للمراجعة والتجربة.
> قبل الإطلاق الرسمي يفضّل بناء ملف CSS مضغوط بدل الـ CDN حتى تصير السرعة أفضل.
